Mnet Plus CC 字幕提取器 v3.1.0
================================

安装：
1. 打开 Edge/Chrome 扩展管理页面：
   edge://extensions/  或  chrome://extensions/
2. 开启「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本文件夹（MnetPlus_CC字幕提取器）。
   注意：文件夹里必须有 manifest.json、utils.js、parsers.js、
         page-hook.js、content.js 这 5 个文件。
4. 打开或刷新 Mnet Plus 视频页面（Ctrl + R）。
5. 页面右下角出现控制面板。

使用：
1. 打开视频，先在播放器里选中你要的字幕轨。
2. 右下角选「字幕语言」（自动 / 全部语言 / 某个具体语言）。
3. 点「提取 CC 字幕」→ 自动扫描整部视频 → 自动下载 .srt。
4. 扫描中再点一次 = 取消。
   「清空」= 清本地缓存；「重新扫描」= 清缓存后立即重扫。

本版支持的字幕资源（自动识别，不靠扩展名）：
- JSON Cue API   /media/v1/public/videos/{id}/captions/{id}/cues
- .cmft 资源     正文实为 WEBVTT
- 其它 .vtt / .webvtt 文本资源

说明：
- 支持任意语言，语言列表由实际收到的字幕动态生成，不写死中文。
- Mnet Plus 只请求播放器当前选中的字幕轨，所以要抓另一种语言，
  必须先在播放器里切换，再点一次按钮（结果会累积）。
- 导出时会显示每种语言的条数与时间覆盖范围；若末尾缺失会提示「可能不完整」。
- 扫描过程中不需要观看视频。
- 遇到问题按 F12 看 Console，搜 [MnetCC] 即可看到详细日志。
  如需关闭日志，把 utils.js 顶部的 DEBUG 改成 false。

右下角出现红色「扩展内部组件加载失败」怎么办？
- 这是 v3.1.0 新增的兜底提示，说明扩展脚本没注入进来（不是字幕解析的问题）。
- 按面板上写的两步做：① 扩展管理页点「重新加载」（🔄）  ② 回页面按 F5。
- 正常情况下控制台应该能看到两行：
     [MnetCC] page-hook 已就绪（MAIN world，零依赖）
     [MnetCC] content 已就绪

全部处理在本地完成，不上传任何字幕或登录信息，不申请任何权限。
