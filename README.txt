Mnet Plus CC 字幕提取器

安装：
1. 解压 MnetPlus_CC_Subtitle_Extension.zip。
2. 打开 Edge/Chrome 扩展管理页面：
   edge://extensions/ 或 chrome://extensions/
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的文件夹。
5. 打开或刷新 Mnet Plus 视频页面。
6. 页面右下角出现“提取 CC 字幕”按钮。
7. 点击按钮，工具会自动扫描整部视频并下载 MnetPlus_zh_CN.srt。

说明：
- 当前版本提取简体中文字幕（zh_CN）。
- 扫描过程中不需要观看视频。
- 新视频打开后刷新页面即可继续使用。
